## Overview

Stockroom is an inventory and back-office admin template for **Next.js 16 and Tailwind CSS 4**, built the shadcn/ui way: Radix UI primitives, variants with `class-variance-authority`, a `cmdk` command palette and shadcn's token names. Every screen works with typed sample data, ready to connect to your own backend.

## Features

- **7 working screens** – Dashboard, Products, Orders and order detail, Customers, Analytics, Settings, and sign-in screens: sorting, filter chips with counts, search, pagination, bulk actions, a create/edit drawer with validation, order actions with confirmations, and a ⌘K command palette
- **50+ components** with a components gallery
- **Light and Graphite (dark) themes**, chosen per viewer, with no flash on load
- **Design tokens** – every colour, size and duration in one CSS file
- **Responsive** from 320 px phones to 1920 px screens
- **Accessibility** – WCAG 2.2 AA target: keyboard operation, focus return, and contrast tested for every token pair in both themes
- **Static and secure** – every page prerendered, with a strict per-page Content-Security-Policy
- **One-command quality gate** – lint, typecheck, tests, build, a static-route check, a bundle budget and a security-header check
